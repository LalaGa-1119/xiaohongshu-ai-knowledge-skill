# 生图评测集

本文件既是验收标准，也是回归测试集。每项按 `0=失败、1=可接受、2=优秀` 评分。任何硬门槛失败时，本页直接返工。

## 硬门槛

1. **文字准确**：要求出现的中英文完整、正确、清晰，并属于正确的说话人或物品。
2. **概念准确**：画面没有增加错误技术结论，也不与确认过的脚本矛盾。
3. **角色一致**：拉拉与猫咪保留固定特征；猫咪必须一只耳朵竖起、一只耳朵折叠。
4. **肢体正常**：没有多余的爪子、手指、四肢、脸、尾巴或重复身体部位。
5. **物品连续**：书、卡片、挂牌和工具的方向、结构及前后状态合理。
6. **版式正确**：3:4 竖版；解释文字位于顶部或底部；只有气泡可以悬浮；主场景位于中间。
7. **发布安全**：不复制参考博主水印，不冒充他人，不无理由放入第三方标志。

## 质量评分项

- 钩子是否清楚
- 是否一页一个重点
- 小白是否看得懂
- 故事或动作是否服务概念
- 标题与主体词是否醒目
- 字体层级是否清楚
- 留白与扫读体验
- 手绘风格是否一致
- 表情尺度是否合适
- 角色比例是否一致
- 颜色是否克制
- 画面证据是否支持文案

所有硬门槛通过后，12 项质量评分至少达到 18/24。

## 历史修改形成的回归用例

### E01：沉睡的 Skill 被触发

**场景**：猫咪趴在桌上平摊打开的 `SKILL.md` 书上睡觉，一块悬挂的任务牌掉下来把猫咪砸醒。第一格拉拉手里不拿卡片。

**必须满足**：

- 拉拉气泡为：`Skill 明明在这里，让它帮我整理一下，它怎么没醒？`
- 气泡属于拉拉，不能属于闭眼睡觉的猫咪。
- 下方书本继续平摊打开，方向与第一格一致。
- 掉下的是悬挂挂牌，不是来源不明的卡片或三折书。
- 挂牌使用白话任务，例如把一段长文整理成总结、重点和待办。

### E02：什么任务适合做成 Skill

**场景**：拉拉与猫咪讨论适用条件。

**必须满足**：

- 使用不需要产品经理经验的小白例子。
- 清楚展示“重复、输出固定、结果可检查”。
- 可用例子：反复把长文整理成`总结 / 重点 / 待办`，再检查三项是否齐全。
- 不得只说“整理需求”或“用户反馈”等小白不熟悉的词。

### E03：猫咪肢体

**场景**：猫咪正面坐着。

**必须满足**：正面只有两只前爪；一只耳朵竖起、一只折叠；身体小而瘦；只有一条箭头尾巴。

### E04：人物表情

**场景**：拉拉恍然大悟，猫咪作出反应。

**必须满足**：表情生动但不过火；既不能像严肃职场宣传人物，也不能尖叫、扭曲或变成夸张鬼脸。

### E05：封面识别

**场景**：主体词和固定角色共同介绍本篇内容。

**必须满足**：主体词是最大文字；缩略图尺寸下仍能看清主题；角色服务标题而不抢标题。
